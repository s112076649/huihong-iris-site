# 汇虹数智科技 · HUIHONG

> 一把长在身体里的钥匙 · A Key That Lives Inside You

汇虹数智科技官方落地页 · 虹膜识别 B2B 解决方案提供商。

- **核心资产**：自主可控的虹膜识别核心源代码
- **模式**：按客户场景定制锻造模组（政企安防 · 金融风控 · 医疗身份 · 冷钱包等）
- **总部**：深圳 · 深港数智智谷

## 技术栈

- 纯静态 HTML / CSS / JavaScript（零构建）
- Three.js（Hero 虹膜 WebGL 渲染 · GLSL shader）
- GSAP + ScrollTrigger（滚动动效 · 数字 counter · Pin-scrub 虹膜解剖）
- 设计：Neuralink 纯黑 × Anduril 橙红打击
